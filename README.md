# ConfluenceElm

ConfluenceElm: a high-performance, event-driven service engine for real-time collaboration, featuring auto-scaling and concurrent rendering capabilities.

ConfluenceElm is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/ConfluenceElm.git`
2. `cd ConfluenceElm`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
